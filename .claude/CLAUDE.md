# Portfolio project notes

This is the React 19 + Vite portfolio for Mehmood Ul Haq, at https://mehmoodulhaq570.netlify.app. `npm run build` prerenders every route to static HTML (see README.md).

## How to work in this repo
- Put every change on a new branch and open a PR. Never commit straight to `main`.
- Check the Netlify deploy preview before reporting a PR as ready.
- Ask the owner before merging each PR. Approval for one PR doesn't carry over to the next.
- After a merge, pull `main` and confirm the change is live.
- Retry network commands, because the connection drops often.
